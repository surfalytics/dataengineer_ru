# Глоссарий: Staff Engineer: Leadership beyond the management track (Will Larson)

Единые слова для всех глав. Правила: навык `book-summary`, раздел «Translation guide».
Колонка «Как пишем»: термин в обратных кавычках = оставляем английским; обычное слово = пишем по-русски (английский в скобках при первом упоминании).
Колонка «Не писать»: варианты, которые `check.py --glossary` считает ошибкой.

| English | Как пишем | Не писать | Пояснение |
|---|---|---|---|
| Staff engineer | Staff-инженер | `staff engineer`, штатный инженер, стафф-инженер | Уровень выше `Senior`. Название роли, не переводим |
| Staff-plus | `Staff+` | стафф-плюс | Общее имя для `Staff`, `Senior Staff`, `Principal` и выше |
| Senior engineer | Senior-инженер | `senior engineer`, старший инженер, сеньор | Уровень, на котором многие компании не ждут повышения |
| Principal engineer | Principal-инженер | `principal engineer`, главный инженер | Уровень выше `Staff` |
| Distinguished engineer | `Distinguished engineer` | заслуженный инженер | Самый высокий уровень инженерной лестницы |
| individual contributor | `IC` (`individual contributor`) | индивидуальный участник, рядовой сотрудник | Инженер без подчинённых |
| engineering manager | `engineering manager` | инженерный менеджер, менеджер разработки | Руководитель инженеров с подчинёнными |
| management track | путь менеджера (`management track`) | управленческий трек, менеджерская дорожка | Карьера через управление людьми |
| career ladder | `career ladder` | карьерная лестница | Описание уровней и ожиданий от каждого |
| career level | `career level` | уровень карьеры | Уровень, на котором компания не требует роста дальше. Обычно `Senior` |
| dual-track ladder | двойная лестница (`dual-track`) | двухтрековая лестница | Две ветки роста: `IC` и менеджер |
| promotion | повышение | промоушен, продвижение | Переход на следующий уровень |
| promotion packet | `promotion packet` | пакет на повышение, промо-пакет | Документ с доказательствами для комитета, который решает о повышении |
| title | должность (`title`) | титул | Название уровня. Автор спорит, насколько оно важно |
| tech lead | техлид (`tech lead`) | технический лидер, тех-лид | Ведёт технические решения одной команды. Это один из четырёх типов `Staff` |
| Architect | `Architect` | — | Тип `Staff`: отвечает за направление и качество в одной области |
| Solver | `Solver` | решатель | Тип `Staff`: уходит туда, где горит, и решает трудную проблему |
| Right Hand | `Right Hand` | правая рука | Тип `Staff`: помогает руководителю и расширяет его влияние |
| archetype | архетип | шаблон роли | Типичная форма работы Staff-инженер. У автора их четыре |
| Staff project | `Staff project` | проект уровня стафф, стафф-проект | Заметный проект, который показывает, что человек работает на уровне `Staff` |
| sponsor | спонсор (`sponsor`) | покровитель | Человек выше по уровню, который выбирает вас для возможностей и выступает за вас |
| sponsorship | спонсорство | покровительство | Активная поддержка: вас называют в разговорах о возможностях. Это не менторство |
| mentorship | менторство | наставничество | Советы и разбор опыта. Автор отделяет от спонсорства |
| visibility | заметность (`visibility`) | видимость | Насколько люди в компании и вне её знают о вашей работе |
| being in the room | быть в комнате (`in the room`) | в помещении | Участие в решениях, где обсуждают приоритеты и ресурсы |
| network | сеть контактов (`network`) | нетворк, сеть | Связи с коллегами из других команд и компаний |
| peers | коллеги того же уровня (`peers`) | пиры | Другие `Staff+` инженеры |
| executive | руководитель высшего звена (`executive`) | экзек, топ | `VP`, `CTO` и выше |
| stakeholder | стейкхолдер | заинтересованное лицо | Человек вне команды, чьё мнение влияет на решение |
| engineering strategy | `engineering strategy` | инженерная стратегия | Набор решений о том, как инженерия достигнет целей компании |
| technical vision | видение (`vision`) | техническое видение | Картина, куда ведёт технику на 1–3 года. Растёт из нескольких стратегий |
| design doc | `design doc` | документ дизайна, дизайн-документ | Короткий текст с описанием решения и вариантов. Из пяти таких пишут стратегию |
| technical direction | технические решения и курс (`technical direction`) | техническое направление | Выбор, как команда строит систему |
| technical quality | техническое качество (`technical quality`) | качество техники | Надёжность, скорость разработки и простота кода |
| technical debt | технический долг | техдолг | Плохие решения, за которые потом платят временем |
| hot spot | `hot spot` | горячая точка | Часть системы, где чаще всего ломается и больше всего боли |
| leverage point | `leverage point` | рычаг, точка рычага | Место, где небольшая работа заметно улучшает качество |
| technical vector | `technical vector` | технический вектор | Общее направление изменений, например «все сервисы на одну базу» |
| quality program | программа качества (`quality program`) | — | Постоянная работа над качеством с метриками и владельцем |
| best practice | `best practice` | лучшая практика | Правило, которое команда принимает как общее |
| glue work | `glue work` | клей, работа-клей | Невидимая работа, которая связывает команды и помогает им двигаться |
| trade-off | компромисс (`trade-off`) | торговля, обмен | Выигрыш в одном свойстве стоит потери в другом |
| alignment | согласованность с руководством (`alignment`) | выравнивание | Вы работаете в том же направлении, что и руководство |
| authority | власть, полномочия | авторитет | Люди, которые принимают решения и назначают приоритеты |
| snacking | `snacking` | перекусы, снекинг | Авторский термин: брать лёгкие задачи ради быстрой пользы вместо важных |
| preening | `preening` | прихорашивание | Авторский термин: выбирать заметную работу ради статуса |
| existential issue | вопрос выживания (`existential issue`) | экзистенциальная проблема | Проблема, от которой зависит выживание компании или продукта |
| skip-level | `skip-level` | через уровень | Встреча с руководителем вашего руководителя |
| platform team | платформенная команда (`platform team`) | команда платформы | Команда, которая строит общие инструменты для других команд |
| Meritocrat | `Meritocrat` | меритократ | Тип компании: ценит результат. Автор противопоставляет `Proceduralist` |
| Proceduralist | `Proceduralist` | процедуралист | Тип компании: ценит процесс и порядок |
