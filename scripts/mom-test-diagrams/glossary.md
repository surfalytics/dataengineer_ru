# Глоссарий: The Mom Test (Rob Fitzpatrick)

Единые слова для всех глав. Правила: навык `book-summary`, раздел «Translation guide».
Колонка «Как пишем»: термин в обратных кавычках = оставляем английским; обычное слово = пишем по-русски (английский в скобках при первом упоминании).
Колонка «Не писать»: варианты, которые `check.py --glossary` считает ошибкой.

| The Mom Test | `The Mom Test` | мамин тест, тест для мамы | Название книги и набор правил: вопросы настолько хорошие, что даже мама не соврёт |

| customer conversation | разговор с клиентом | клиентское интервью, кастдев-интервью | Короткая беседа, чтобы узнать о проблемах человека. Не продажа и не опрос |
