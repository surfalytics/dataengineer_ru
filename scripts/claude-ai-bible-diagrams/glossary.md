# Глоссарий: Claude AI Bible (Stephen Clear)

Единые слова для всех глав. Правила — в навыке `book-summary`, раздел «Translation guide».
Колонка «Как пишем»: термин в обратных кавычках = оставляем английским; обычное слово = пишем по-русски (английский в скобках при первом упоминании).
Колонка «Не писать»: варианты, которые `check.py --glossary` считает ошибкой.
Формы взяты из глоссариев `claude-code-diagrams`, `ai-engineering-diagrams` и `redefining-de-ai-diagrams`.
Названия продуктов (Claude, Opus, Sonnet, Haiku, Cowork, Claude Code, Projects) не в таблице: пишем как есть, без кавычек.
