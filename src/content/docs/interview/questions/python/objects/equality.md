В чём разница между `==` и `is`?

## Ответ

`==` сравнивает **значения** объектов. Обычно это сравнение выполняется методом `__eq__()`.

`is` проверяет **идентичность**: являются ли две переменные ссылками на один и тот же объект в памяти.

```python
a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)  # True: содержимое одинаковое
print(a is b)  # False: это разные объекты

print(a == c)  # True
print(a is c)  # True: обе переменные указывают на один объект
```

Для сравнения обычных значений используют `==`:

```python
name = "Python"

if name == "Python":
    print("Значения равны")
```

`is` обычно используют для сравнения с singleton-объектами, прежде всего с `None`:

```python
value = None

if value is None:
    print("Значение отсутствует")

if value is not None:
    print("Значение существует")
```

Не следует использовать `is` для сравнения чисел и строк. Некоторые такие объекты могут переиспользоваться интерпретатором, поэтому результат проверки идентичности зависит от деталей реализации.

Коротко:

- `a == b` — равны ли значения;
- `a is b` — один ли это объект;
- для `None` — `is None` и `is not None`.
