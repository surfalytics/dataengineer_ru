Какие типы данных в Python являются изменяемыми и неизменяемыми? Как работает ссылочная модель данных?

## Ответ

**Неизменяемый объект** (`immutable`) нельзя изменить после создания. Операция, похожая на изменение, создаёт новый объект.

Основные неизменяемые типы: `int`, `float`, `bool`, `str`, `tuple`, `bytes`, `frozenset`.

**Изменяемый объект** (`mutable`) можно изменить на месте, сохранив его идентичность.

Основные изменяемые типы: `list`, `dict`, `set`, `bytearray`.

| Свойство | Immutable | Mutable |
| --- | --- | --- |
| Можно изменить объект на месте | нет | да |
| Примеры | `int`, `str`, `tuple`, `frozenset` | `list`, `dict`, `set`, `bytearray` |
| Результат изменения | создаётся новый объект | меняется существующий объект |

## Ссылочная модель

Переменная в Python — имя, связанное с объектом в памяти. Присваивание другой переменной не копирует объект: новое имя связывается с тем же объектом.

```python
a = [1, 2, 3]
b = a

b.append(4)

print(a)  # [1, 2, 3, 4]
print(a is b)  # True
```

`a` и `b` указывают на один список, поэтому изменение через `b` видно через `a`.

Чтобы получить независимую поверхностную копию списка:

```python
a = [1, 2, 3]
b = a.copy()

b.append(4)

print(a)  # [1, 2, 3]
print(b)  # [1, 2, 3, 4]
print(a is b)  # False
```

## Важный нюанс

Сам `tuple` неизменяем, но может содержать ссылки на изменяемые объекты. Внутренний объект можно изменить:

```python
data = ([1, 2], 3)
data[0].append(4)

print(data)  # ([1, 2, 4], 3)
```

Изменилась не структура кортежа, а список, на который хранится ссылка внутри него.
