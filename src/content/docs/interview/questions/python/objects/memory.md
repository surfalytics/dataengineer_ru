Как в Python освобождается память?

## Ответ

По счётчику ссылок: у каждого объекта записано, сколько имён на него смотрят, и как только счётчик доходит до нуля, объект убирают сразу. Но счётчик не справляется с циклом. Если два объекта ссылаются друг на друга, у каждого счётчик единица, хотя снаружи на них никто не смотрит. Ровно для таких случаев есть сборщик мусора, он периодически ищет замкнутые группы.
