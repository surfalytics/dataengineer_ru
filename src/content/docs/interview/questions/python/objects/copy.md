В чём разница между поверхностной и глубокой копией?

## Ответ

Поверхностная копия (*shallow copy*) создаёт новый внешний объект, но вложенные объекты остаются общими с оригиналом: копируются ссылки на них. Поэтому изменение вложенного изменяемого объекта будет видно через обе копии.

Глубокая копия (*deep copy*) рекурсивно копирует объект вместе с вложенными структурами. Изменения в скопированных вложенных объектах не влияют на оригинал.

В Python обычно используют `copy.copy()` для поверхностной копии и `copy.deepcopy()` для глубокой.
