Какая типизация используется в Python?

## Ответ

Python использует **динамическую** и **сильную** типизацию.

## Динамическая типизация

Тип принадлежит объекту и определяется во время выполнения. Имя переменной можно связать с объектами разных типов:

```python
value = 5
print(type(value))  # <class 'int'>

value = "пять"
print(type(value))  # <class 'str'>
```

Отдельно объявлять тип переменной перед использованием не нужно.

## Сильная типизация

Python не выполняет неявные преобразования между несовместимыми типами:

```python
result = 1 + "2"
# TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

Нужно преобразовать значение явно:

```python
result = 1 + int("2")
print(result)  # 3
```

Сильная типизация не означает полное отсутствие неявных преобразований. Совместимые числовые типы могут приводиться автоматически, например `1 + 2.5` даёт `3.5`.

## Duck typing

Для Python важнее поддерживаемое объектом поведение, чем конкретный класс: «если объект ведёт себя как утка, его используют как утку».

```python
def print_length(value):
    print(len(value))


print_length("Python")
print_length([1, 2, 3])
```

Функция принимает разные типы, если они поддерживают `len()`.

## Аннотации типов

Аннотации не меняют выполнение кода и обычно не проверяются интерпретатором автоматически. Они служат документацией и помогают IDE, линтерам и статическим анализаторам вроде `mypy`.

```python
def greet(name: str) -> str:
    return f"Привет, {name}!"
```

Аннотации особенно полезны на границах модулей и в публичных интерфейсах.
