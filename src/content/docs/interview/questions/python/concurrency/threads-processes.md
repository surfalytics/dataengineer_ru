Отличие многопоточности от мультипроцессинга?

## Ответ

Далее рассматривается обычная сборка CPython с включённым GIL.

### Мультипоточность

Один процесс, в котором запускается несколько потоков.

Все потоки делят одну память.

GIL (Global Interpreter Lock) в CPython не позволяет выполнять два потока одновременно на разных ядрах.

Хорошо подходит для задач, где нужно ждать (загрузка файлов, работа с сетью), а не вычислять.

### Мультипроцессинг

Каждый процесс работает отдельно, у каждого — своя память.

Использует все ядра процессора.

Подходит для тяжёлых вычислений (например, обучение модели или парсинг больших данных).
