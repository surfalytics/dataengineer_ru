Что такое GIL?

## Ответ

GIL (Global Interpreter Lock) — это глобальная блокировка в стандартной сборке CPython. В пределах одного интерпретатора только поток, удерживающий GIL, исполняет Python-байткод. В сборках со свободной многопоточностью GIL можно отключить.

Из-за GIL многопоточный Python-код не масштабируется по CPU: в вычислительных задачах (CPU-bound) потоки фактически работают последовательно. Но для I/O-bound задач — ожидания сети, файлов или базы данных — многопоточность может быть полезной, так как поток освобождает GIL на время ожидания.

Например, если наш бэкенд написан на Python и обращается к сервису, запускающему ML-модель, мы можем параллельно посылать запросы и ожидать ответы сервиса, вместо того чтобы отправлять их по одному.
