Что такое `list` в Python и какова сложность основных операций?

## Ответ

`list` — динамический массив ссылок на объекты.

Обращение по индексу занимает `O(1)`: адрес элемента вычисляется напрямую по его позиции.

Добавление через `append()` в среднем занимает `O(1)`. Когда свободное место заканчивается, Python выделяет массив большего размера и копирует в него все ссылки. Такой конкретный вызов стоит `O(n)`, но память выделяется с запасом, поэтому расширение происходит редко. Средняя стоимость `append()` остаётся `O(1)` — это называется амортизированной сложностью.

Вставка или удаление в начале либо середине списка занимает `O(n)`, потому что нужно сдвинуть оставшуюся часть массива.

## Сложность основных операций

| Операция | Сложность |
| --- | --- |
| Обращение по индексу `items[i]` | `O(1)` |
| `append()` | амортизированно `O(1)`, в худшем случае `O(n)` |
| Вставка в начало или середину | `O(n)` |
| Удаление из начала или середины | `O(n)` |
