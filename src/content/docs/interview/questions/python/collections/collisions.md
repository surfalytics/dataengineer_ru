Что такое коллизия в `dict` и как Python с ней справляется?

## Ответ

Коллизия — это когда разные ключи после хеширования метят в одну ячейку таблицы. Она неизбежна: ячеек конечное число. Python решает её открытой адресацией, то есть не строит цепочку, а по правилу пробует следующие ячейки, пока не найдёт свободную или искомый ключ. При этом сверяет не только хеш, но и сами ключи через `==`, поэтому совпадение хешей ничего не портит. Чем плотнее таблица, тем длиннее пробы, и при заполнении примерно на две трети Python берёт таблицу побольше и раскладывает всё заново.
