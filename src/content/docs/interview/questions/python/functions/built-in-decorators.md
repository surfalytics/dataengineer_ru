Основные встроенные декораторы — `@property`, `@staticmethod` и `@classmethod`.

`property` позволяет обращаться к методу как к атрибуту, например `user.name`. Через setter можно проверять присваиваемое значение. `staticmethod` не получает автоматически ни экземпляр, ни класс — подходит для вспомогательных функций. `classmethod` получает класс первым аргументом и часто используется для альтернативных конструкторов.

Из стандартной библиотеки назову `@abstractmethod` для объявления абстрактных методов и `@dataclass` для автоматической генерации `__init__`, `__repr__`, `__eq__`.

Если копнут глубже, можно добавить:

- **Наследование:** `classmethod` получает класс наследника, поэтому `return cls(...)` создаст экземпляр наследника.
- **Абстрактные методы:** вместе с `ABC` запрещают создавать экземпляры класса, пока остаются нереализованные абстрактные методы.
- **Dataclass:** использует аннотированные поля, но сам не проверяет типы значений.
- **Property:** getter вызывается при каждом чтении; автоматического кеширования нет.
