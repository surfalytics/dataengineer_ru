Чем отличаются глобальные и локальные переменные в Python? Когда нужно ключевое слово `global`?

## Ответ

**Локальная переменная** создаётся внутри функции и доступна только в её локальной области видимости.

**Глобальная переменная** создаётся вне функций, в области видимости модуля. Её можно читать внутри функций без дополнительных объявлений.

```python
x = 5  # Глобальная переменная


def func():
    x = 10  # Локальная переменная
    print(x)


func()      # 10
print(x)    # 5
```

Локальная переменная `x` внутри `func()` скрывает глобальную `x`, но не изменяет её.

## Почему возникает `UnboundLocalError`

Если внутри функции есть присваивание имени, Python считает это имя локальным во всей функции. Поэтому попытка прочитать его до присваивания вызывает ошибку.

```python
counter = 0


def increment():
    counter = counter + 1


increment()  # UnboundLocalError
```

Здесь правая часть пытается прочитать локальную `counter`, которой ещё не присвоено значение.

## Изменение глобальной переменной

Чтобы изменить глобальную переменную внутри функции, нужно объявить её через `global`:

```python
counter = 0


def increment():
    global counter
    counter += 1


def get_counter():
    return counter  # Для чтения global не нужен


increment()
print(get_counter())  # 1

increment()
print(get_counter())  # 2
```

`global` нужен для перепривязки имени в глобальной области видимости. Для простого чтения глобальной переменной он не требуется.
