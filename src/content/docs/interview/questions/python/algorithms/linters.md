Что такое линтер?

## Ответ

**Линтер** выполняет статический анализ исходного кода без запуска программы и находит потенциальные ошибки, подозрительные конструкции и нарушения правил проекта.

Линтер может обнаруживать:

- неиспользуемые импорты и переменные;
- недостижимый код;
- подозрительные сравнения;
- неправильную обработку исключений;
- слишком сложные функции;
- нарушения соглашений о стиле;
- некоторые проблемы безопасности и производительности.

## Линтер, formatter и type checker

Это разные слои проверки:

| Инструмент | Назначение |
| --- | --- |
| Линтер | Ищет потенциальные ошибки и нарушения правил |
| Formatter | Автоматически приводит код к единому стилю |
| Type checker | Проверяет согласованность аннотаций типов |

Например:

- Ruff, Flake8 и Pylint — линтеры;
- Black и Ruff formatter — форматтеры;
- mypy и Pyright — статические анализаторы типов.

Один инструмент может закрывать несколько задач, но сами задачи остаются разными.

## Ruff

Ruff — быстрый линтер для Python с большим набором правил и поддержкой безопасных автоматических исправлений.

```bash
# Проверить проект
ruff check .

# Применить доступные автоматические исправления
ruff check --fix .

# Отформатировать код
ruff format .
```

Проверка типов выполняется отдельным инструментом:

```bash
mypy .
```

## Где запускать

Линтер обычно запускают:

1. в IDE — для быстрой обратной связи;
2. через pre-commit — перед созданием коммита;
3. в CI — чтобы код с нарушениями не попал в основную ветку.

Formatter отвечает за единый внешний вид кода. Линтер сообщает, какие конструкции потенциально ошибочны или подозрительны. Type checker отдельно проверяет типы.
