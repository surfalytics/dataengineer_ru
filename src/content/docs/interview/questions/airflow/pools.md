**Pool** — именованный набор слотов, общий для задач, которым он назначен. Он помогает ограничить нагрузку на конкретный ресурс сразу из нескольких DAG.

Допустим, PostgreSQL выдерживает четыре параллельные выгрузки. Создаём пул `source_pg` на четыре слота и назначаем его всем выгрузкам из этой БД. Четыре обычные задачи займут по одному слоту, остальные подождут. Тяжёлой выгрузке можно назначить `pool_slots=2`. Тогда рядом с ней останется место для двух обычных задач.

- Пул ограничивает только назначенные ему задачи. Для остальных используется их собственный пул или `default_pool`.
- Слот учитывает экземпляр задачи с заданным весом. Если код каждой задачи откроет десять соединений, четыре однослотовые задачи могут открыть сорок соединений. Вес и размер пула выбирают с учётом реальной нагрузки.
- Для отложенных задач (`deferred`) можно настроить, должны ли они продолжать занимать слоты пула.
