В таблице `articles` у каждой статьи есть массив `tags` типа `text[]`. GIN извлекает из массивов отдельные теги. Для каждого тега индекс хранит ссылки на версии строк, в которых он встречается. Так можно искать статьи по содержимому массива.

<IndexSearch method="gin" />

На схеме `R1`–`R4` — короткие обозначения адресов строк. Запрос с `@>` ищет статьи, в которых присутствуют сразу оба тега.

```sql
CREATE INDEX articles_tags_idx ON articles USING gin (tags);
```

<details>
<summary>Что происходит, когда один тег встречается очень часто?</summary>

Короткий список адресов помещается в индексную запись как posting list. Для большого числа адресов PostgreSQL использует отдельное posting tree. При записи одного массива приходится учитывать несколько индексных ключей.

</details>
