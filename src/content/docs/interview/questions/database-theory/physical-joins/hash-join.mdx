Hash Join часто используют для соединения больших неотсортированных наборов по равенству ключей. Движок обычно строит хеш-таблицу по меньшему входу и ищет в ней совпадения для строк второго. Если хеш-таблица не помещается в память, движок может временно записать часть данных на диск. Чтение и запись замедляют соединение.

В таблице A записаны участники, в таблице B — занятия. Ключ в обеих таблицах — номер группы. Соединим их по этому ключу, чтобы получить для каждого участника все занятия его группы.

<details>
<summary>Почему строки из A1 и B1 не дали совпадения?</summary>

У ключей 1 и 3 одинаковый остаток от деления на 2, поэтому строки попадают в партиции с номером 1. В хеш-таблице B1 есть только ключ 3. Поиск ключа 1 ничего не находит. В партициях A0 и B0 ключ 2 встречается по два раза, поэтому соединение даёт четыре пары.
