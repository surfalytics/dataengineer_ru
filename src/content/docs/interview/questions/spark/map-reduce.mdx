**Map** применяет функцию к каждому элементу отдельно. **Reduce** объединяет значения по заданному правилу. Например, если нужны количества слов, map превращает каждое слово в пару `(слово, 1)`, а reduce складывает счётчики одного слова. Для поиска максимума правило объединения было бы другим.

<SparkDataFlow mode="map-reduce" />

В первой входной партиции лежат слова «кот, пёс, кот», во второй — «пёс, кот». Проследим только за словом **«кот»**:

1. **Map.** В первой партиции получаются две пары `("кот", 1)`, во второй — одна. При `reduceByKey` Spark может сложить значения одного ключа прямо на стороне чтения. Поэтому для слова «кот» дальше идут частичные суммы **2** и **1**.
2. **Shuffle.** Обе суммы нужны одной задаче. В примере слово «кот» направляем в выходную партицию P0, «пёс» — в P1. Задача для P0 читает свой локальный блок с двойкой и получает единицу со второго executor.
3. **Reduce.** Когда значения одного ключа собраны, задача складывает `2 + 1`. Результат для «кот» — **3**, для «пёс» — **2**.

В RDD API `reduceByKey` — ленивая трансформация. Она возвращает распределённый набор пар с одним результатом на ключ. Метод `reduce` — action, которая объединяет элементы всего RDD в одно значение и возвращает его на driver.
