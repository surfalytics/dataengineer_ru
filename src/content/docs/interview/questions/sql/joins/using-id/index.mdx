Предскажите строки для `SELECT * FROM t1 LEFT JOIN t2 USING (id)`. Что изменится при `INNER JOIN` и `FULL JOIN`? Сначала посмотрите на две таблицы, затем сравните свой ответ с результатом выбранного JOIN.

<SqlJoinLab exercise />

<details>
<summary>Почему Борис встречается дважды и откуда берутся NULL?</summary>

В `t1` у Бориса `id = 2`. В `t2` этому ключу соответствуют две строки — Омск и Тула. Обе пары удовлетворяют равенству. Поэтому даже `INNER JOIN` вернёт **две** строки с Борисом.

- **LEFT — 4 строки.** Обе пары Бориса, а также Анна и Вера с `NULL` в `city`.
- **INNER — 2 строки.** Обе пары Бориса.
- **FULL — 5 строк.** К результату LEFT добавится `(4, NULL, 'Пермь')`. Общий столбец `id` берёт значение 4 с правой стороны.

`USING (id)` объединяет два одноимённых ключевых столбца в один столбец результата. Совпавшие пары строк при этом сохраняются все. Без `ORDER BY` порядок вывода может отличаться от схемы.

</details>
