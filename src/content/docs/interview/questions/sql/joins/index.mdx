**JOIN** определяет, какие пары строк попадут в результат и какие строки сохранятся без пары. Переключите вид соединения. Вверху подсвечиваются исходные строки, внизу к пустой таблице добавляется по одной строке результата. Порядок в схеме выбран для наглядности. SQL гарантирует порядок выдачи только с `ORDER BY`.

<SqlJoinLab />

| Вид | Какие строки попадут в результат |
| --- | --- |
| `LEFT JOIN` | Все совпавшие пары и по одной строке для каждой левой строки без пары. Справа у неё `NULL`. |
| `RIGHT JOIN` | Все совпавшие пары и по одной строке для каждой правой строки без пары. Слева у неё `NULL`. |
| `FULL JOIN` | Все совпавшие пары и все строки без пары с обеих сторон. |
| `INNER JOIN` | Только пары, для которых условие соединения истинно. |
| `CROSS JOIN` | Все сочетания левой строки с правой. Для двух таблиц по две строки получатся четыре пары. |

При `USING (id)` ключ `id` выводится один раз. При обычном равенстве два значения `NULL` между собой не совпадают. Что сохранит внешний JOIN и как сервер найдёт совпадения — разные вопросы.
