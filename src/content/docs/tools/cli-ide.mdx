## Что это

**IDE** (Integrated Development Environment) — редактор кода с подсказками, отладчиком и Git.
**CLI** (Command Line Interface) — работа с файлами, облаком и API через терминал.
Инженер данных каждый день использует и то, и другое.

## Когда что использовать

| Задача | Что взять |
|---|---|
| Python, dbt, YAML, Terraform | VS Code или PyCharm |
| Писать SQL и смотреть данные в базе | DBeaver, DataGrip или расширение SQLTools в VS Code |
| Быстро посмотреть CSV, JSON, Parquet | CLI: `csvkit`, `jq`, `xsv` |
| Работа с облаком (S3, BigQuery, Azure) | CLI облака: `aws`, `gcloud`, `az`, `yc` |
| Долгие задачи на удалённом сервере | `tmux` — сессия не пропадёт при обрыве SSH |

## Сравнение IDE

| | VS Code | PyCharm CE | DBeaver CE | DataGrip |
|---|---|---|---|---|
| Цена | Бесплатно | Бесплатно | Бесплатно | Платно |
| Python | Да, через расширение | Да, лучший выбор | Нет | Нет |
| SQL и базы данных | Частично, через расширения | Только в платной версии | Да | Да, лучший выбор |
| dbt, YAML, Terraform | Да | Частично | Нет | Нет |
| Скорость | Быстрый | Тяжелее | Средняя | Средняя |

<Aside type="tip" title="Наш совет">
Начните с **VS Code** + **DBeaver**. Этого хватит для 90% задач. PyCharm и DataGrip берите, когда упрётесь в ограничения.
</Aside>

## Лучшие практики

- Держите настройки IDE и `.editorconfig` в репозитории — у всей команды одинаковое форматирование.
- Настройте линтер и форматтер: `ruff` для Python, `sqlfluff` для SQL.
- Выучите 10 горячих клавиш своей IDE: поиск файла, поиск по проекту, мультикурсор, переход к определению.
- Не храните пароли к базам в настройках IDE в открытом виде. Используйте переменные окружения или менеджер секретов.
- В терминале используйте `fzf` для поиска по истории команд — это экономит много времени.
