Портал — это **база знаний** для инженеров данных: инструменты, лучшие практики, IDE и полезные ссылки. Всё бесплатно.

## Как пользоваться

<Steps>

1. Прочитайте, [кто такой инженер данных](/start/what-is-de/) и чем он занимается.

2. Откройте [дорожную карту](/start/roadmap/). Найдите свой уровень.

3. Идите по темам уровня по порядку. На каждой странице есть: что это, когда использовать, лучшие практики и ссылки.

4. Нашли полезный ресурс? [Добавьте его через Pull Request](https://github.com/surfalytics/dataengineer_ru).

</Steps>

## Метки у ресурсов

| Метка | Что значит |
|---|---|
| `Новичок` `Средний` `Продвинутый` | Уровень сложности |
| `Инструмент` `Документация` `Статья` `Видео` `Книга` `Тренажёр` | Тип материала |
| `🇷🇺 Рус` `🇬🇧 Англ` | Язык материала по ссылке |
| `⭐ Рекомендуем` | Наш выбор — начните с него |
