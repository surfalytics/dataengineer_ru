## Как понять, что уровень пройден

- **Основы** — пишете SQL с `JOIN` и оконными функциями, работаете в терминале и Git.
- **Junior** — можете построить простой пайплайн: API → хранилище → дашборд.
- **Middle** — разворачиваете пайплайн в облаке, обрабатываете большие данные в Spark, следите за качеством данных.
- **Senior** — проектируете архитектуру, выбираете инструменты, ведёте команду.
