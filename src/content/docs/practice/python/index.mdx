## Что это

**Python** — язык программирования. Это второй главный язык данных после SQL.

## Зачем это знать

- SQL работает только внутри базы. Python может всё остальное: скачать данные из API, прочитать файл, отправить письмо.
- Большинство инструментов данных написаны на Python или управляются из Python: Airflow, dbt, Spark (PySpark), pandas.
- Python легко читать. Это хороший первый язык.

## Как используют

| Кто | Задачи |
|---|---|
| Инженер данных | Пишет ETL, забирает данные из API, пишет DAG для Airflow, тесты, работает с PySpark |
| Аналитик данных | Чистит данные в pandas, считает статистику, строит графики, работает в Jupyter |

## Что будет в практике

- Типы данных, переменные, списки и словари
- Условия и циклы
- Функции
- Работа с файлами: CSV и JSON
- Запросы к API с `requests`
- Основы pandas
