**Python** — главный язык данных после SQL. Для работы не нужно знать весь язык. Нужен **базовый минимум**. Его мы и разбираем.

## Зачем знать Python

- SQL работает только внутри базы. Python делает всё остальное: берёт данные из API, читает файлы, чистит, грузит в базу.
- Airflow, dbt, Spark (PySpark), Polars, DuckDB управляются из Python.
- Python легко читать. Это хороший первый язык.

## Как используют

| Кто | Задачи |
|---|---|
| Инженер данных | Пишет ETL, забирает данные из API, пишет DAG для Airflow, тесты, логирование |
| Аналитик данных | Чистит данные, считает статистику, работает с файлами и API |

## Как заниматься

Идите по порядку. Каждый урок: короткое объяснение, код, задания.

Главное правило: **решайте сами, без AI**. Сначала напишите код, потом открывайте решение. Сравните свой результат с блоком «Проверка».

Если вы уже умеете программировать, пропустите уроки 4–11. Начните с [окружений](/practice/python/environments/).
