## Что это

**Docker** — инструмент для запуска программ в контейнерах.
Контейнер — это программа вместе со всем, что ей нужно для работы: библиотеки, настройки, версия языка.

## Зачем это знать

- Программа работает одинаково на ноутбуке, у коллеги и на сервере.
- Базу данных, Airflow или BI-инструмент можно запустить одной командой. Не нужно ничего ставить вручную.
- Пайплайны в продакшене часто работают как контейнеры (Kubernetes, ECS, Cloud Run).

## Как используют

| Кто | Задачи |
|---|---|
| Инженер данных | Пишет `Dockerfile` для пайплайна, запускает Postgres и Airflow локально через `docker compose` |
| Аналитик данных | Поднимает локальную базу или Metabase, чтобы попробовать запросы и дашборды |

## Что будет в практике

- Образ и контейнер: `docker run`, `ps`, `stop`, `logs`
- Свой образ: `Dockerfile`, `docker build`
- Тома и порты
- `docker compose`: Postgres + pgAdmin одной командой
