**Статистика** — это набор способов ответить на вопрос «что говорят данные» одним-двумя числами. Не нужно смотреть на 1000 строк. Достаточно посчитать среднее, разброс и проверить, не случайна ли разница.

## Зачем знать статистику

- **Среднее часто врёт.** Пять больших заказов поднимают средний чек на треть. Медиана этого не замечает.
- **Метрики нужно проверять.** Конверсия выросла с 10% до 12,5%. Это эффект или случайность? Для ответа нужен A/B-тест.
- **Качество данных.** Выбросы и странный разброс часто означают ошибку в пайплайне.
- **Собеседования.** Среднее, медиана, p-value, доверительный интервал — частые вопросы для аналитиков и инженеров данных.

## Как статистику используют в работе

| Кто | Задачи |
|---|---|
| Аналитик данных | Описывает метрики, ищет выбросы, проверяет A/B-тесты, считает доверительные интервалы |
| Инженер данных | Пишет проверки качества данных: выбросы, резкие скачки, перекос распределения. Считает перцентили для мониторинга |

## Как устроен курс

Каждую тему вы решаете **двумя способами**: на Python и на SQL (DuckDB). Так вы поймёте и идею, и как её посчитать в базе.

- **Python** — обычный, без внешних библиотек. Только `csv` и `statistics` из стандартной поставки. Не нужны pandas, numpy и Jupyter.
- **SQL** — DuckDB на вашем компьютере. Как в [курсе SQL](/practice/sql/).
- **Данные** — три небольших CSV-файла: заказы, маркетинг по дням, A/B-тест.

## Как заниматься

Идите по урокам по порядку. Каждый урок: короткое объяснение, код на Python и SQL, потом задания.

Главное правило: **решайте сами, без AI**. Сначала посчитайте, потом открывайте решение. Сравните свой ответ с блоком «Проверка».

<Aside type="note" title="Что нужно знать заранее">
Немного Python (переменные, списки, циклы) и немного SQL (`SELECT`, `GROUP BY`). Если их нет, начните с [базового минимума SQL](/practice/sql/). Python разбираем здесь только то, что нужно для статистики.
</Aside>
