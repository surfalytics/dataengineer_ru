## Что это

**Git** — система контроля версий. Она хранит историю всех изменений в коде.
**GitHub** — сайт, где хранят Git-репозитории и работают над кодом вместе.

## Зачем это знать

- Можно вернуться к любой старой версии кода.
- Несколько человек могут менять один проект и не мешать друг другу.
- Изменения проходят ревью через Pull Request. Ошибки ловят до продакшена.
- В современной работе с данными весь код живёт в Git: SQL, dbt, Airflow, Terraform.

## Как используют

| Кто | Задачи |
|---|---|
| Инженер данных | Делает ветку, коммитит изменения пайплайна, открывает Pull Request, проходит CI/CD |
| Аналитик данных | Хранит SQL и модели dbt в Git, делает ревью запросов коллег |

## Что будет в практике

- `git init`, `clone`, `status`, `add`, `commit`
- Ветки: `branch`, `switch`, `merge`
- Работа с GitHub: `push`, `pull`, Pull Request
- Конфликты и как их решать
- `.gitignore`
