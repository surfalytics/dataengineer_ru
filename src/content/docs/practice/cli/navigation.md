Три команды закрывают большую часть работы в терминале: где я, что здесь лежит, перейти в другое место.

## pwd — где я

`pwd` (print working directory) печатает папку, в которой вы сейчас:

```bash
pwd
```

```
/home/maria/cli-practice
```

Это **текущая папка**. Большинство команд работают относительно неё.

## Пути

Путь — адрес файла или папки.

- **Абсолютный путь** начинается с `/`: `/home/maria/cli-practice/data`. Он работает из любой папки.
- **Относительный путь** считается от текущей папки: `data/customers.csv`.

Специальные имена:

| Имя | Что значит |
|---|---|
| `~` | Ваша домашняя папка |
| `.` | Текущая папка |
| `..` | Папка уровнем выше |
| `/` | Корень файловой системы |

В Linux и macOS разделитель — `/`, а не `\`, как в Windows.

## cd — перейти

```bash
cd data          # в папку data внутри текущей
cd ..            # на уровень выше
cd ~             # в домашнюю папку (или просто cd)
cd ~/cli-practice/logs   # по полному пути от домашней папки
cd -             # назад, туда, где были до этого
```

## ls — что здесь

```bash
ls               # имена файлов и папок
ls data          # что лежит в папке data
ls -l            # подробно: права, владелец, размер, дата
ls -lh           # то же, размер в КБ и МБ
ls -a            # все файлы, включая скрытые
```

## Скрытые файлы

Файлы, имя которых начинается с точки, — **скрытые**: `.env`, `.gitignore`, `.bashrc`. Обычный `ls` их не показывает. `ls -a` показывает.

В скрытых файлах обычно лежат настройки: конфиг shell, Git, пароли и ключи для подключения к базам. Вы будете часто их открывать.

:::tip
Пишите путь и жмите `Tab`. Shell допишет имя сам. Если вариантов несколько, нажмите `Tab` два раза.
:::

## Практика

Все задания — в папке `~/cli-practice`. Нет папки? Скачайте файлы на странице [Установка](/practice/cli/setup/).

### Задание 1

Перейдите в папку `cli-practice` и напечатайте полный путь к ней.

**Проверка:** путь заканчивается на `/cli-practice`. Например, `/Users/maria/cli-practice` на macOS или `/c/Users/maria/cli-practice` в Git Bash.

<details>
<summary>Решение</summary>

```bash
cd ~/cli-practice
pwd
```

</details>

### Задание 2

В папке `inbox` шесть видимых файлов, но есть ещё один, скрытый. Найдите его.

**Проверка:** скрытый файл — `.env`.

<details>
<summary>Решение</summary>

```bash
ls -a inbox
```

`.` и `..` в списке — это сама папка и папка выше. Они есть в каждой папке.

</details>

### Задание 3

Посмотрите размеры файлов в папке `data`. Какой файл самый большой?

**Проверка:** `events.csv`, около 363 КБ.

<details>
<summary>Решение</summary>

```bash
ls -lh data
```

</details>

### Задание 4

Перейдите в папку `logs/archive`. Вернитесь в `cli-practice` командой с `..`. Потом снова прыгните в `logs/archive` одной короткой командой.

**Проверка:** после последней команды `pwd` показывает путь, который заканчивается на `/cli-practice/logs/archive`.

<details>
<summary>Решение</summary>

```bash
cd logs/archive
cd ../..
cd -
pwd
```

</details>
