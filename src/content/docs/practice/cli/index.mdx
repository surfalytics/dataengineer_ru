**CLI** (Command Line Interface) — работа с компьютером через текстовые команды в терминале.
Вместо мыши вы пишете команду, например `ls` или `cd`, и нажимаете Enter.

## Зачем знать CLI

- **Серверы и облака работают без окон.** На виртуальной машине в облаке есть только терминал.
- **У каждого инструмента данных есть CLI.** `dbt`, `aws`, `gcloud`, `az`, `snow`, `duckdb`, `docker`, `git` — всё это команды в терминале.
- **AI-агенты работают в терминале.** Claude Code, Codex, Gemini CLI запускают те же команды: `ls`, `grep`, `git`, `dbt run`. Чтобы понять, что делает агент, и разрешить или запретить команду, нужно читать CLI.
- **Команду можно повторить.** Её можно сохранить в скрипт, запустить по расписанию, отправить коллеге. Клики мышью так не повторить.
- **Доступ к серверам и базам — через ключи.** SSH-ключи и ключи сервисных аккаунтов создают и настраивают в терминале.

## Как CLI используют в работе

| Кто | Задачи в терминале |
|---|---|
| Инженер данных | Подключается к серверу по SSH, запускает пайплайны, работает с облаком (`aws s3 ls`), читает логи, настраивает ключи сервисных аккаунтов |
| Аналитик данных | Запускает `dbt run` и Python-скрипты, смотрит большие CSV-файлы, работает с Git |
| Оба | Работают с AI-агентами (Claude Code, Codex), ставят инструменты, правят конфиги (`.env`, `profiles.yml`) |

## Как устроен курс

Вы работаете в настоящем терминале на своём компьютере. Мы дадим папку с учебными файлами: продажи, клиенты, логи пайплайна, конфиг. Все задания — на этих файлах.

| [Что такое shell](/practice/cli/shell/) | bash и zsh, приглашение `$`, первые команды |
| [Навигация](/practice/cli/navigation/) | `pwd`, `cd`, `ls`, скрытые файлы |
| [Файлы и папки](/practice/cli/files/) | `mkdir`, `touch`, `cp`, `mv`, `rm` |
| [Чтение файлов](/practice/cli/read-files/) | `cat`, `head`, `tail`, `less`, `wc` |
| [Поиск файлов](/practice/cli/find/) | Шаблоны `*` и `?`, `find`, `du` |
| [grep и конвейеры](/practice/cli/grep-pipes/) | `grep`, конвейер `\|`, `sort`, `uniq`, `cut`, `>` и `>>` |
| [Переменные и PATH](/practice/cli/variables/) | Переменные, `export`, `PATH`, `which`, файлы `.env` |
| [Права, скрипты и архивы](/practice/cli/permissions/) | `chmod`, запуск скриптов, `sudo`, `tar`, `curl` |
| [SSH и ключи](/practice/cli/ssh-keys/) | Ключи SSH, `~/.ssh/config`, ключ сервисного аккаунта для базы данных |

Git в этом курсе не разбираем. Для него будет отдельная практика.

## Как заниматься

Идите по урокам по порядку. Каждый урок: короткое объяснение, примеры, потом задания.

Главное правило: **решайте сами, без AI**. Напишите команду, проверьте результат, и только потом открывайте решение.
