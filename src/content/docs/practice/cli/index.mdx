## Что это

**CLI** (Command Line Interface) — работа с компьютером через текстовые команды в терминале.
Вместо мыши вы пишете команду, например `ls` или `cd`.

## Зачем это знать

- Серверы и облака часто не имеют графического интерфейса. Есть только терминал.
- Почти все инструменты данных запускаются из терминала: `dbt`, `git`, `docker`, `python`, `aws`.
- Команды можно сохранить в скрипт и повторять. Клики мышью повторить нельзя.

## Как используют

| Кто | Задачи |
|---|---|
| Инженер данных | Подключается к серверу по SSH, запускает пайплайны, работает с облаком (`aws s3 ls`), смотрит логи |
| Аналитик данных | Запускает `dbt run`, Python-скрипты, быстро смотрит большие CSV-файлы |

## Что будет в практике

- Навигация: `pwd`, `ls`, `cd`
- Файлы: `cp`, `mv`, `rm`, `mkdir`
- Чтение файлов: `cat`, `head`, `tail`, `less`
- Поиск и фильтры: `grep`, `wc`, `sort`, `uniq`, конвейеры `|`
- Переменные окружения и права на файлы
