**SQL** (Structured Query Language) — язык для работы с данными в базах данных.
Ему больше 50 лет. Его используют почти все компании.

## Зачем знать SQL

- **Данные живут в базах.** Postgres, MySQL, Snowflake, BigQuery, ClickHouse, DuckDB — везде SQL.
- **Он простой.** Запрос читается почти как предложение: «выбери столбцы из таблицы, где условие».
- **Он работает там, где лежат данные.** Не нужно выгружать миллионы строк в Excel. База посчитает сама.
- **Запрос легко проверить и повторить.** Это текст. Его можно сохранить, отправить коллеге, положить в Git.

## Как SQL используют в работе

| Кто | Что делает с SQL |
|---|---|
| Инженер данных | Пишет трансформации в хранилище, модели dbt, загрузки (ELT), проверки качества данных |
| Аналитик данных | Отвечает на вопросы бизнеса, считает метрики, готовит данные для дашбордов |
| BI-разработчик | Строит витрины и датасеты для BI-инструментов |
| Data Scientist | Собирает выборки для моделей и проверяет гипотезы |

## SQL и Excel

Если вы работали в Excel, многое будет знакомо.

| Excel | SQL |
|---|---|
| Лист с данными | Таблица |
| Фильтр | `WHERE` |
| Сортировка | `ORDER BY` |
| Сводная таблица | `GROUP BY` и агрегаты: `SUM`, `COUNT`, `MIN`, `MAX` |
| ВПР (VLOOKUP) | `JOIN` |

Разница: SQL работает с миллиардами строк и с несколькими таблицами сразу.

## Как устроен курс

| Страница | Что внутри |

## Как заниматься

Мы не даём редактор в браузере. Вы ставите базу на свой компьютер. Так вы сразу учитесь работать как на работе: терминал, файл базы, SQL-клиент.

<Steps>

1. Установите **DuckDB** и скачайте файл учебной базы. Это 5 минут. Инструкция: [Установка](/practice/sql/setup/).

2. Посмотрите, [какие таблицы есть в базе](/practice/sql/datasets/).

3. Идите по урокам по порядку. Читайте пример, запускайте его у себя, меняйте его.

4. Решайте задания в конце урока. Сверяйте свой ответ с подсказкой «Проверка».

5. Только потом открывайте «Решение».

</Steps>

## Правило: решаем без AI

<Aside type="caution" title="Не используйте ChatGPT, Claude, Copilot и другие AI-помощники в этом курсе">
AI напишет любой запрос из курса за секунду. Но тогда вы ничему не научитесь.
</Aside>

Почему это важно:

- **На собеседовании AI не будет.** Задачи по SQL дают почти на каждом собеседовании на инженера и аналитика данных.
- **AI ошибается.** Чтобы найти ошибку в чужом запросе, нужно уметь писать запросы самому.
- **Навык появляется только от практики.** Как в спорте: смотреть, как тренируется другой, бесполезно.

Как решать без AI:

- Застряли — перечитайте урок. Ответ почти всегда там.
- Разбейте задачу на шаги. Сначала `SELECT * ... LIMIT 10`, потом фильтр, потом сортировка.
- Читайте ошибку. DuckDB пишет, в какой строке проблема.
- Ищите в [документации DuckDB](https://duckdb.org/docs/stable/sql/introduction). Это нормально, так делают все.
- Открывайте решение, только если потратили 15–20 минут. Потом закройте его и напишите запрос сами.

AI — отличный инструмент для работы. Им стоит пользоваться, когда вы уже умеете делать задачу сами. Об этом у нас есть раздел [AI для инженера данных](/ai/ai-tools/).
