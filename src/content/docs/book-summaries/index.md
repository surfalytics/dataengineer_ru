Здесь собраны конспекты важных книг на русском. Каждый конспект разбит по главам. В нём есть главная мысль, ключевые термины, практические выводы, вопросы для самопроверки и схемы.

> Это собственные пересказы, а не переводы. За полным текстом и примерами идите в оригинал.

## Как устроен конспект

- **Обзор книги.** Зачем читать, для кого, как устроена книга, список глав.
- **Страница главы.** Главная мысль, разбор по разделам, таблицы и схемы.
- **Ключевые термины.** Английские термины с коротким пояснением.
- **Что это значит на практике.** Выводы для работы инженера данных.
- **Вопросы для самопроверки.** Три-четыре вопроса на главу.
