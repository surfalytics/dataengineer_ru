## Установка

Автор советует `native installer` — родной установщик. Он сам обновляет программу в фоне. Это важно, ведь инструмент меняется очень часто:

```bash
# macOS, Linux, WSL
curl -fsSL https://claude.ai/install.sh | bash

# Windows PowerShell
irm https://claude.ai/install.ps1 | iex

# Windows CMD
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

Команды PowerShell и CMD нельзя путать: приглашение `PS C:\` означает PowerShell. Установщик работает несколько минут и ничего не пишет на экран, так что не волнуйтесь. Затем откройте новый терминал и проверьте версию:

```bash
claude --version
```

```text
2.1.325 (Claude Code)
```

Если команды нет, обычно папки `~/.local/bin` нет в `PATH`: добавьте её в `.zshrc` или `.bashrc`. Если что-то работает не так, `claude doctor` проверит настройку окружения. А если инструкции устарели, автор советует попросить AI помочь с установкой.

Установить Claude Code через Homebrew, WinGet, apt, dnf и apk тоже можно, но обновлять версию придётся самим. Установка через npm осталась, но её больше не советуют по умолчанию. На Windows без WSL нужен Git for Windows, иначе Claude Code использует PowerShell вместо Bash.

## Вход

При первом запуске команды `claude` агент просит выбрать стиль текста в терминале и спрашивает, доверяете ли вы папке, в которой он запущен. Затем он просит войти. С подпиской откроется браузер, и данные входа сохранятся локально.

Второй путь — `API key` от Anthropic в переменной окружения. Автор предупреждает, что это быстро становится дорого: агент снова и снова отправляет в модель большие куски кода. Весной 2026 года Anthropic объявила, что в каждую подписку войдёт некоторое число API-кредитов для такого входа. Как это будет работать на практике, пока неясно.

Обычно начинают с Pro. Max 5x даёт в 5 раз больше лимита, а Max 20x — в 20 раз. Бесплатного тарифа нет, но `harness` Claude Code можно запускать с открытыми моделями через Ollama. Аккаунт меняют командами `/logout` и `/login`. Длинные сессии, `subagent` и `extended thinking` расходуют лимит использования (`quota`) быстрее, чем обычный чат.

## Первая сессия

Запускайте Claude Code из папки проекта:

```bash
cd /path/to/your/project
claude
```

Экран приветствия показывает данные сессии и недавние разговоры, а `/help` — список команд.

## Своя statusline

`Statusline` — это строка внизу терминала с данными сессии. Про неё автора чаще всего спрашивают на курсах. Запустите `/statusline` и опишите словами, что хотите видеть:

```text
/statusline Покажи папку, модель, ветку git и есть ли изменения
```

Claude Code сам пишет небольшой скрипт и подключает его в `~/.claude/settings.json`:

```json
"statusLine": {
  "type": "command",
  "command": "bash ~/.claude/statusline-command.sh"
}
```

Скрипт лежит в домашней папке, поэтому работает во всех проектах. Он запускается при каждом обновлении строки, так что медленный код тормозит сессию. Ветка и модель берутся из локальных данных и почти ничего не стоят. Наш простой вариант — [`ch02_statusline.sh`](https://github.com/surfalytics/dataengineer_ru/blob/main/scripts/claude-code-code/ch02_statusline.sh), а тест подаёт ему на вход такой же JSON, какой передаёт Claude Code:

```bash
bash scripts/claude-code-code/ch02_statusline_test.sh
```

```text
📁 lyrics-trainer | 🤖 Opus | 🌿 main (clean)
📁 lyrics-trainer | 🤖 Opus | 🌿 main (dirty)
```

## Первый вопрос и цикл запроса

В готовом проекте начните с вопроса только на чтение: «Что делает этот проект?». Claude Code сам читает нужные файлы, и копировать код в чат не нужно. Это одно из первых отличий агента от обычного окна чата.

Каждый запрос проходит цикл запроса (`request loop`): Claude Code планирует шаги, читает проект и решает, что делать. Если нужно только чтение, ответ приходит сразу. Запись или shell-команда проходят через запрос разрешения (`permission gate`), и вы одобряете, отклоняете или меняете действие.

![Цикл запроса Claude Code: чтение сразу даёт ответ, а запись и shell-команды ждут вашего согласия](/assets/claude-code-up-and-running/ch02-request-loop.png)

Шаги 5–7 справа идут только с вашего согласия. Сессия показывает, какие файлы агент читает и какие правки предлагает, поэтому циклом легко управлять. Если агент пошёл не туда, нажмите ESC: это лучше, чем потом исправлять ущерб. Подробнее о правах — в главе 5.

## Спросите Claude Code об экране приветствия

Автор спросил агента, зачем нужны данные на экране приветствия: папка (`cwd`), модель, ветка git и оболочка. Ответ был такой: эта сводка показывает главные настройки, с которыми работает сессия. Если запись пошла не в ту ветку или папку, первым делом проверьте эту сводку.

## Lyrics-trainer: первый doghouse

Автору нужно было выучить слова песни, а запоминать ему теперь трудно: в детстве он схватывал всё сразу, а сейчас нужно много повторов. Ему хватило бы крошечного инструмента, который показывает строки по одной. Это классический `doghouse`. Из-за авторских прав вместо песни он берёт сонет 18 Шекспира. Позже тренажёр вырастет до `cabin`.

Начните с пустой папки: `mkdir lyrics-trainer`, `cd lyrics-trainer`, `claude`. Наш вариант `prompt`:

```text
Сделай одностраничное веб-приложение, чтобы учить текст по одной строке.
Возьми сонет 18 Шекспира. Показывай одну строку и кнопку «Дальше».
После последней строки начинай с первой.
Только HTML, CSS и JavaScript: без фреймворков, сборки и зависимостей.
Если хватит одного файла index.html, сделай один файл.
```

Автор признаётся, что составил свой `prompt` вместе с Claude Code. Агент попросил разрешения на запись и создал один файл `index.html`: строки лежат в массиве, а кнопка увеличивает номер текущей строки. Наша версия ([полный файл](https://github.com/surfalytics/dataengineer_ru/blob/main/scripts/claude-code-code/ch02_lyrics_trainer/index.html)):

```js
let pos = 0;  // номер текущей строки, с нуля
function show() {
  lineBox.textContent = lines[pos];
  counterBox.textContent = `Строка ${pos + 1} из ${lines.length}`;
}
document.getElementById("next").addEventListener("click", () => {
  pos = (pos + 1) % lines.length;  // после последней строки снова первая
  show();
});
```

Проверка без браузера нажимает «Дальше» 5 раз:

```bash
node scripts/claude-code-code/ch02_check_trainer.mjs
```

```text
Строка 1 из 4 | Shall I compare thee to a summer's day?
Строка 2 из 4 | Thou art more lovely and more temperate:
Строка 3 из 4 | Rough winds do shake the darling buds of May,
Строка 4 из 4 | And summer's lease hath all too short a date;
Строка 1 из 4 | Shall I compare thee to a summer's day?
Строка 2 из 4 | Thou art more lovely and more temperate:
```

Страницу можно открыть, не выходя из сессии: `!` запускает shell-команду, например `! open index.html` на macOS. Сервер здесь не нужен, а позже автор предупредит: можно забыть, что запущенный агентом сервер всё ещё работает.

Агент сам объяснил мелочь, о которой автор не подумал бы спросить: `min-height` у строки не даёт кнопке прыгать. Ещё он предложил режим, где строка скрыта, пока вы не вспомните её сами, но первая версия осталась простой. Модель недетерминированная, поэтому ваш результат будет другим.

## Итоги главы

- `Native installer` обновляет Claude Code сам, поэтому автор советует его.
- Команды `claude --version` и `claude doctor` показывают, всё ли установлено верно.
- Подписка обычно выгоднее `API key`, ведь агент отправляет в модель много токенов.
- Чтение агент делает сам, а запись и shell-команды ждут вашего разрешения.
- ESC останавливает агента сразу, и это лучше, чем исправлять ошибку потом.
- Для `doghouse` первой версии хватает одного HTML-файла.

## Ключевые термины

| Термин | Значение |
|---|---|
| `native installer` | Установщик, который сам обновляет Claude Code |
| лимит использования (`quota`) | Сколько работы даёт подписка |
| `statusline` | Строка с данными сессии внизу терминала |
| цикл запроса (`request loop`) | План, чтение, решение, ответ или изменение |
| запрос разрешения (`permission gate`) | Пауза перед записью или shell-командой до вашего согласия |

## Что это значит на практике

- Знакомство с репозиторием dbt начните с вопросов только на чтение: «Какие модели строят витрину заказов?».
- Выведите ветку git в `statusline`, чтобы не править пайплайн не в той ветке.
- Читайте каждый запрос разрешения, особенно для команд, которые пишут в базу или облако.
