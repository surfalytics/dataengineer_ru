**Главная мысль:** DataStream API покрывает лишь часть задач Flink. Для запроса к таблице, поиска последовательности событий и анализа связей между объектами авторы предлагают разные интерфейсы.

## О чём глава

После эксплуатации задания в главе «[Работа с Flink и потоковыми приложениями](/book-summaries/engineering/stream-processing-with-apache-flink/10-operating-streaming-applications/)» авторы завершают книгу картой экосистемы. Описанные возможности относятся к Flink 1.7.

## Остальная часть экосистемы Flink

### DataSet

Для конечного набора данных DataSet поддерживал пакетные преобразования и итерации. Вычисление можно было повторять заданное число раз или до сходимости. В версии книги DataSet и DataStream использовали разные среды исполнения. Объединение этих путей авторы описывали как направление развития.

### Table API и SQL

Оба интерфейса выражают реляционные операции над таблицами. Для SQL Flink использовал Apache Calcite при разборе и оптимизации запросов. Запрос можно было встроить в программу или отправить через SQL-клиент.

### FlinkCEP

Библиотека поверх DataStream ищет заданные последовательности событий. Например, одно действие может выглядеть обычным, а несколько действий в заданном порядке укажут на подозрительное поведение. Найденные совпадения можно передать следующему оператору.

### Gelly

Библиотека для графов опиралась на DataSet и пакетные итерации. Например, вершины и рёбра можно было подготовить средствами Table API, а затем передать графовому алгоритму.

## Сообщество

Авторы различают вопросы пользователей, обсуждение разработки и объявления о встречах. Примеры форматов общения в книге — тематические рассылки, блоги, местные встречи и конференция Flink Forward.

## Итоги главы

- DataSet предназначался для конечных данных.
- SQL описывает реляционные вычисления.
- FlinkCEP распознаёт шаблоны в потоке.
- Gelly работает со связями в графе.
- Результаты разных видов анализа можно передавать дальше.
- Выбор интерфейса зависит от вопроса к данным.

## Ключевые термины

| Термин | Значение |
| --- | --- |
| `CEP` | Поиск заданных комбинаций событий. |

## Что это значит на практике

Сначала сформулируйте, что требуется найти: агрегат, последовательность или связи объектов. Затем выбирайте интерфейс, в котором эта задача выражается непосредственно.
