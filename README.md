# Инжиниринг Данных — dataengineer.ru

Русскоязычный образовательный портал об аналитике и инжиниринге данных: курсы,
книги, тренажёры и дорожные карты для аналитиков, BI-разработчиков и инженеров данных.

Сайт построен на [Astro](https://astro.build/) +
[Starlight](https://starlight.astro.build/) и размещён на GitHub Pages
(домен `dataengineer.ru`).

## Локальная разработка

```bash
npm install        # установить зависимости (нужен Node 20+)
npm run dev        # локальный сервер: http://localhost:4321
npm run build      # сборка статического сайта в dist/
npm run preview    # предпросмотр собранного сайта
```

## Структура контента

Весь контент — это Markdown-файлы в `src/content/docs/`, сгруппированные по разделам:

| Папка | Раздел в навигации |
|---|---|
| `processing/` | Обработка и аналитика |
| `tools/` | Инструменты |
| `ai/` | AI |
| `career/` | Карьера |
| `resources/` | Книги и Материалы |
| `community/` | Сообщество и Управление |
| `about/` | О проекте |

## Как добавить страницу

1. Создайте `.md`-файл в нужной папке `src/content/docs/<раздел>/`.
2. Добавьте front matter:

   ```yaml
   ---
   title: Название страницы
   description: Краткое описание для поиска и SEO.
   sidebar:
     order: 10          # порядок в боковом меню (меньше — выше)
   tags:
     - sql
   ---
   ```

3. Пишите контент на русском в Markdown. Изображения кладите в `public/assets/`
   и ссылайтесь на них как `/assets/имя-файла.png`.
4. Откройте Pull Request.

Условные обозначения в материалах: 🇷🇺 / 🇬🇧 — язык материала, ⭐ — наша рекомендация.

## Навигация и поиск

- Порядок разделов задаётся в `astro.config.mjs` (`sidebar`), порядок страниц —
  полем `sidebar.order` во front matter.
- Поиск работает на [Pagefind](https://pagefind.app/) с поддержкой русской морфологии
  (включается автоматически при сборке).

## Деплой

Push в ветку `main` запускает GitHub Actions (`.github/workflows/deploy.yml`),
который собирает сайт и публикует на GitHub Pages. Домен задаётся файлом
`public/CNAME`.
